# GitHub Pages

Esta página foi publicada utilizando o GitHub Pages com o objetivo de disponibilizar online o projeto PortfolioHUB – Portfólio Web Pessoal.

O site foi desenvolvido com HTML, CSS e JavaScript, apresentando de forma organizada informações acadêmicas, projetos pessoais, habilidades técnicas e formas de contato profissional.

A publicação no GitHub Pages permite o fácil acesso ao portfólio por professores, recrutadores e profissionais da área de tecnologia, funcionando como uma vitrine digital para apresentação profissional.

## Objetivo

Fortalecer a presença profissional online e demonstrar conhecimentos em desenvolvimento web, organização de repositórios, versionamento com Git e publicação de projetos na web.

## Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript
* Git
* GitHub
* GitHub Pages
