# GitHub Pages

Esta pasta representa a publicação do projeto PortfolioHUB utilizando GitHub Pages.

A página foi desenvolvida com HTML, CSS e JavaScript e está disponível online para apresentação do portfólio profissional, projetos acadêmicos e pessoais.

O objetivo é fortalecer a presença profissional digital e facilitar o compartilhamento de projetos com recrutadores, professores e oportunidades profissionais.
