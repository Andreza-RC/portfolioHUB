# PortfolioHUB – Portfólio Web Pessoal

Este projeto consiste no desenvolvimento de um portfólio web pessoal, criado com o objetivo de apresentar minha trajetória acadêmica, habilidades técnicas, projetos desenvolvidos e informações profissionais de forma organizada, moderna e acessível.

A plataforma foi desenvolvida utilizando HTML, CSS e JavaScript, com foco em responsividade, navegação intuitiva e design limpo, permitindo uma boa experiência tanto em dispositivos desktop quanto mobile.

O site reúne informações sobre meu perfil profissional, projetos acadêmicos e pessoais, além de uma seção dedicada ao contato e à apresentação das principais tecnologias utilizadas durante minha formação.

## Funcionalidades

* Apresentação pessoal e profissional
* Exibição de projetos acadêmicos e pessoais
* Organização por categorias no portfólio
* Layout responsivo para diferentes dispositivos
* Interface moderna e intuitiva
* Navegação simples e objetiva
* Seção de contato profissional
* Estrutura preparada para futuras atualizações

## Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript
* Git
* GitHub Pages

## Objetivo

O principal objetivo deste projeto é fortalecer minha presença profissional online, funcionando como uma vitrine digital para demonstrar minhas competências, experiências e evolução na área de tecnologia.
