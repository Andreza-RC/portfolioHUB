# Segurança e Gestão de Usuários

## Gestão de Usuários

O projeto utiliza a plataforma GitHub para gerenciamento de acesso e controle dos arquivos.

O proprietário do repositório é responsável por:

- Gerenciar alterações no projeto
- Aprovar modificações
- Controlar a publicação do conteúdo

## Políticas de Segurança

Foram adotadas as seguintes práticas:

- Utilização de controle de versão através do GitHub
- Organização dos arquivos em diretórios específicos
- Não compartilhamento de credenciais ou senhas
- Controle de alterações através do histórico de commits
- Hospedagem segura utilizando GitHub Pages

## Controle de Acesso

O acesso ao código-fonte é realizado através do repositório GitHub.

O acesso ao portfólio publicado é realizado através do GitHub Pages.

## Apoio do Google GEMINI

O Google GEMINI foi utilizado como ferramenta de apoio para pesquisa de boas práticas de organização, documentação e segurança durante a implantação do projeto.

## Resultado

A estrutura implementada permite rastreabilidade das alterações, organização dos projetos e disponibilização segura do conteúdo.
