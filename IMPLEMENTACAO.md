# Implantação do PortfolioHUB

## 1. Planejamento da Implantação

O projeto foi planejado com o objetivo de centralizar projetos acadêmicos e pessoais em um único ambiente online.

Estrutura criada:

- Projetos Acadêmicos
- Projetos Pessoais
- GitHub Pages
- Documentação dos projetos

## 2. Configuração Inicial

Foi criado um repositório dedicado chamado PortfolioHUB para armazenamento e organização dos projetos.

Foi utilizada a plataforma GitHub para:

- Hospedagem do código
- Controle de versão
- Compartilhamento dos projetos

## 3. Integração com GitHub Pages

O GitHub Pages foi configurado para disponibilizar o portfólio através da web.

Link do projeto:

https://andreza-rc.github.io/portfolioHUB/

## 4. Uso do Google GEMINI

O Google GEMINI foi utilizado como ferramenta de apoio para:

- Planejamento da implantação
- Organização da estrutura
- Apoio na documentação
- Melhoria da navegação do projeto

## 5. Testes Realizados

Foram realizados testes de:

- Navegação do site
- Acesso aos projetos
- Funcionamento dos links
- Organização dos arquivos

## 6. Resultado Final

O PortfolioHUB foi implantado com sucesso, permitindo o acesso aos projetos acadêmicos e pessoais através do GitHub e GitHub Pages.
