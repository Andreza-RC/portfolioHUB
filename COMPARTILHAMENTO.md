# Compartilhamento e Controle de Acesso

## Compartilhamento do Projeto

O projeto foi disponibilizado através das seguintes plataformas:

### GitHub

Repositório utilizado para armazenamento, versionamento e gerenciamento dos arquivos.

Link:
https://github.com/andreza-rc/portfolioHUB

### GitHub Pages

Utilizado para publicação online do PortfolioHUB.

Link:
https://andreza-rc.github.io/portfolioHUB/

## Controle de Acesso

O acesso ao código-fonte é controlado pelo proprietário do repositório através da plataforma GitHub.

O acesso ao site é público para fins acadêmicos e demonstração dos projetos desenvolvidos.

## Benefícios da Solução

- Facilidade de acesso
- Disponibilidade online
- Controle de versões
- Organização dos projetos
- Compartilhamento simplificado

## Resultado

A solução permite o acesso aos projetos de forma organizada e centralizada, mantendo controle sobre as alterações realizadas.
