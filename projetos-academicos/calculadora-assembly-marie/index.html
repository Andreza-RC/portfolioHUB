🧮 Calculadora em Assembly MARIE

Projeto acadêmico - Organização e Arquitetura de Computadores

📌 Sobre o projeto

Esta calculadora foi desenvolvida utilizando Assembly no simulador MARIE. O sistema permite realizar operações matemáticas básicas a partir de entradas do usuário.

⚙️ Funcionalidades

  • Soma
  • Subtração
  • Multiplicação (somas repetidas)
  • Controle de fluxo com decisões

🧠 Tecnologias e conceitos

  • Assembly MARIE
  • Arquitetura de computadores
  • Controle de fluxo (Jump, Skipcond)
  • Loops e manipulação de memória

🔍 Exemplo

Entrada: 1 (soma), 5, 3

Saída: 8
