# 🏨 Sistema de Hotel

## 📌 Descrição
Este projeto consiste na simulação de um sistema de gerenciamento de hotel, desenvolvido como atividade acadêmica.

O sistema tem como objetivo representar o funcionamento básico de um hotel, permitindo o controle de reservas e organização de informações.

---

## ⚙️ Funcionalidades
- Cadastro de hóspedes
- Registro de reservas
- Controle de disponibilidade de quartos
- Simulação de operações básicas de um hotel

---

## 🧠 Conceitos Aplicados
- Lógica de programação
- Estrutura de dados
- Organização de sistemas
- Modelagem de problemas
