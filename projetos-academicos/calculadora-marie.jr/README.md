# 🧮 Calculadora em Assembly MARIE

## 📌 Descrição
Este projeto consiste na implementação de uma calculadora utilizando a linguagem Assembly do simulador MARIE.

O sistema recebe como entrada:
- Tipo de operação (1 = Soma, 2 = Subtração, 3 = Multiplicação, 4 = Divisão)
- Dois números inteiros

## ⚙️ Funcionalidades
- Soma
- Subtração (com verificação de erro)
- Multiplicação (implementada por somas sucessivas)
- Estrutura de decisão com controle de fluxo

## 🧠 Conceitos Aplicados
- Arquitetura de computadores
- Linguagem Assembly (MARIE)
- Controle de fluxo (Jump, Skipcond)
- Manipulação de memória
- Laços de repetição

## 🎓 Disciplina
Organização e Arquitetura de Computadores

## ▶️ Como executar
Executar o código no simulador MARIE, inserindo os valores solicitados via entrada padrão.
## 🔍 Exemplo de uso

Entrada:
1
5
3

Saída:
8
